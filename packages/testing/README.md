# @gripeventsctl/testing

Test helpers shared by the GripEventsCtl packages. This package is **private** (never published) and depends on no other workspace package. A package that uses it adds `"@gripeventsctl/testing": "workspace:^"` under `devDependencies` and names the setup entry in its `vitest.config.ts`.

- `withTempHome(fn)`: a fresh temporary directory set as `HOME`, `USERPROFILE` and `GRIPEVENTSCTL_CONFIG_FILE` for one test, removed afterwards; `fn` receives `{ dir, configFile, env }`. The pieces (`createTempHome`, `removeTempHome`, `saveHomeEnv`, `restoreHomeEnv`, `HOME_ENV_NAMES`) are exported too.
- `@gripeventsctl/testing/setup`: a Vitest `setupFiles` entry that points those variables at a temporary directory for every test file, fails a test that leaves one of the three variables, the derived send log, journal or lock path, or the `writes.send_log` of a config file at that path outside it (the message names the variable; `outsideTempHome(env, root)` is the check), and fails the file if the real home directory's five `.gripeventsctl*` files changed while it ran. It cannot see a store built from an explicit `env` naming another directory, nor a read of the real config; tests pass `withTempHome()`'s `env` for that.
- `guardedPaths(env)`: the config path and the three derived paths by the same rule `@gripeventsctl/core` applies, restated here; `packages/core/src/__tests__/config-paths.test.ts` asserts the two agree.
- `stubOp(script)`: a POSIX shell script named `op` on a temporary directory prepended to `process.env.PATH` until `remove()` is called, recording argv, stdin and environment for each call and answering from the script. `STUB_OP_SUPPORTED` is false on Windows, where a test skips with the reason in its name.
- `fakeClock(start?)`: a manual `Clock` whose `now()` the test sets (`set`) and advances (`advance`), and whose `sleep()` and `timeoutSignal()` fire when the clock passes their due time. `FAKE_CLOCK_START` is the default start.
- `fixtureSecrets()`: a per-run session token, chat token, application token, password, the email (`FIXTURE_EMAIL`) and the `Basic` value; never a literal in a committed file.
- `mockGrip()`: an undici `MockAgent` with `disableNetConnect()` and call history enabled, `assertNoPendingInterceptors()` after each test and `close()` after all; created once per test file and injected as the client's `dispatcher`. An optional `MockGripHooks` argument replaces Vitest's `afterEach` and `afterAll`, so the harness's own test can call the after-each check directly. `MOCK_API_ORIGIN` restates the API origin (core's `headers.test.ts` asserts it equals `API_ORIGIN`; the name says it is the mock's, not the `GRIP_API_ORIGIN` environment variable the client ignores); `gripPool(agent)` is the interceptable pool of that origin; `stderrSink()` collects what the client writes to its `stderr`.
- `fakeTerminal(options?)`: the CLI's `Terminal` seam as a fake with settable TTY flags (`tty`, `stdoutTTY`), scripted `answers` and `hiddenAnswers` (an unscripted prompt rejects), the labels of the prompts shown (`visiblePrompts`, `hiddenPrompts`) and a `screen()` buffer; `write(stream, text)` forwards to the stream and keeps a copy on the screen.
- `runCli(argv, io)`: runs the real CLI program (`runProgram` of `@gripeventsctl/cli`) with `io = { terminal, dispatcher, clock, env, platform? }` and captured streams, and resolves to `{ stdout, stderr, exitCode, error? }`. The CLI is loaded from its built entry (`packages/cli/dist/index.js`) by its place in the repository, because this package depends on no workspace package; `pnpm build` first. A line the command writes past its injected streams, through `process.stdout`, `process.stderr` or `console`, is captured for the duration of the call and returned after the injected output; console arguments are rendered as the console renders them. `captureProcessOutput(fn)` is the capture and `openOutputCapture(sink)` its primitive, both exported: captures may overlap, every open one receives every write, and the streams are put back once the last one closes.
- `linkMcp(server)`: connects a real `McpServer` to an SDK `Client` over `InMemoryTransport.createLinkedPair()` and resolves to `{ client, listTools(), callTool(name, args?), stderr(), stdout(), close() }`: `listTools()` is the `tools` array of one `tools/list` call (empty for a server with no tool), `callTool()` the raw `CallToolResult`, `stderr()` what a handler wrote through `process.stderr` or `console.error` during the calls, and `close()` closes both ends.
- `spawnMcpStdio({ home, env?, entry? })`: starts the built umbrella binary (`packages/gripeventsctl/dist/cli.js mcp`, or `entry`) through `StdioClientTransport` with `PATH`, `HOME`, `USERPROFILE` and `GRIPEVENTSCTL_CONFIG_FILE` pointing at `home` (plus `env`), and resolves to `{ client, listTools(), callTool(), stderr(), close() }`; the transport merges its default inherited set underneath (`HOME`, `LOGNAME`, `PATH`, `SHELL`, `TERM`, `USER` on POSIX), with the harness's values on top. A non-protocol byte on the child's stdout fails the handshake and the promise rejects. `repositoryRoot()` and `umbrellaBinary()` are the paths it resolves.
- `forkWorker(script, env)`, `barrier(workers)`, `killAtIntercept(agent, pathPrefix, worker)`: `child_process.fork` of a built worker script with IPC (`{ child, send(), next(), exited(), stderr() }`), a barrier that waits for every worker's `{ type: "ready" }` and sends `{ type: "go" }` to all at once, and a kill switch that sends `SIGKILL` to the worker the moment the mock agent records a request on a path (the agent's `dispatch` is wrapped and unwraps itself after firing). The test-only workers live under `src/__tests__/workers/` and build to `dist/__tests__/workers/`.
- The envelope builders (`success200`, `failure`, `apiFailure`, `unauthorized401`, `loadBalancer403`, `configLookup200`, `configLookup404`, `containerList200`, `containerNotFound404`, `login200`, `searchPage200`, `searchEntries200`, `searchEmpty200`, `gatedType403`, `profile200`, `throttled429`, `matchAnswer201`, `matchStatus200`, `swipeCapAnswer`, `modePhaseAnswer`, `conflict409`, `conflict409InData`, `chatLatest200`, `chatThread200`, `chatSend200`, `scheduleInfo200`, with the entry helpers `chatThreadEntry`, `chatMessageEntry` and `scheduleEntry`): one per documented answer, each returning the `{ statusCode, data, responseOptions }` shape `intercept().reply(callback)` accepts and each carrying a comment naming the `docs/api/` page and section it mirrors. Ids are small integers from 1 upward, names `Test Person <n>` and companies `Example Org <n>`, messages `synthetic message <n>`, secrets from `fixtureSecrets()`; `envelope-citations.test.ts` checks that every cited heading exists on its page. `jsonReply(statusCode, body, headers?)` builds a JSON reply of any status and body with no page behind it, for an answer no page records; `JSON_HEADERS` is the `content-type` it sets and `GripReply` the shape every builder returns.
