# Platform landscape

This page answers two questions, researched on 2026-10-07.
Is the attendee API documented or wrapped anywhere?
Which other events run on Grip, and how can you tell?
Conventions and labels are in [README.md](README.md).

## Summary

- Nothing public covers the attendee API.
- Grip moved its API documentation behind the organiser login in Q4 2024.
- Grip's only MCP server (beta since July 2026) is for organisers and is read-only.
- Grip has announced automatic blocking and suspension of accounts that script the attendee list. Bulk pulls carry a risk to the user's own account.
- The attendee API shows only the caller's own organiser's live events. Grip's public config lookup confirms any event by slug without a login.
- That lookup and two deep-research passes verified about forty other events on Grip (table below).

## Is the attendee API documented or wrapped anywhere?

**No** (web research 2026-10-07).
Nothing public documents or wraps `api-prod.grip.events` as an attendee uses it.
The research found none of these:

- a developer portal, an OpenAPI or Swagger file, a Postman collection, an SDK;
- an MCP registry entry (Smithery, mcp.so, MCPMarket, Glama, the modelcontextprotocol/servers list);
- a Zapier, Make, n8n, Workato, Pipedream or Composio app;
- an apis.guru or SwaggerHub entry, a Hacker News thread, a write-up.

Grip's roadmap says why.
The entry "Enhanced Security and Streamlined API Documentation with Swagger" (Released, Q4 2024) states that the API documentation used to be public.
It now sits behind the organiser-dashboard login, and "most" of it is private.

`GET https://api-prod.grip.events/` answers "Welcome to the Intros API".
The vendor's legal name is Intros.at Ltd, and the old API host was `api.intros.at`.

The Wayback CDX index lists `api.intros.at/1/public/container/...` and `api.intros.at/1/public/session/...` answering 200 in 2020 and 2021.
The snapshots were not opened.

The organiser API is a separate thing from the attendee API on this site.
It shares the host and the data model, but it takes an organiser's token, not an attendee's `user_token`.
The Swagger document behind the organiser dashboard login was not looked for.

## Blocking of attendee-list scraping

Grip's roadmap entry "Automatic Blocking of Attendee List Scraping" was fetched on 2026-10-07.
It reads: Timeframe "Now", expected release Q4 2026, platform Grip Engage, available as standard.

It says Grip "now automatically stops participants who use scripts to scrape your attendee list":

- the account is logged out on web and mobile;
- its access to the event is suspended for breaching the End User Licence Agreement;
- there are "eight independent layers of protection";
- the organiser gets a "Scraping Insights dashboard" naming who triggered it.

Grip's support article "Data scraping" tells organisers to hide the attendee list and to add a no-scraping clause to their terms.

Whether the blocking is live for a given container cannot be seen from outside.
For container `9840`, the directory dump and the profile fetches of 2026-10-06 did not trip it, and the token still worked all morning on 2026-10-07.
Treat every bulk pull as a suspension risk to the user's own account.

## How to check whether an event runs on Grip

Use the public config lookup by slug, with the bootstrap bearer and no login (**verified live 2026-10-07**).
See [containers.md](containers.md#config-by-slug) for the request and the answer.
A 200 means the slug exists on Grip. A 404 `No results found for this container name` means only that this slug is unknown.

Slug guessing works.
`<eventname><year>` in lower case resolved Money20/20, Mining Indaba, Breakbulk, Spring Fair, Source Fashion, Bett Asia, Big 5 Global, AXC, ITC Vegas, MEBAA and HumanX in one run on 2026-10-07.

## How to recognise a Grip-hosted event from the outside

Read from Grip's help centre (`support.grip.events`, fetched 2026-10-07) and from the sources in the table below:

- The default web app is `https://matchmaking.grip.events/<slug>`, with endings `/event-login`, `/app` and `/app/home`. The slug is the event's fixed "system name", and it is what `config?container_name=` takes.
- Organisers can put a branded hostname in front (`connect.`, `app.`, `networking.<event domain>`). The help centre tells them to CNAME it to `matchmaking02.grip.events`, so a DNS lookup settles it.
- The browser's network tab shows calls to `https://api-prod.grip.events/1/`. The help centre's Grip Manage to Grip Engage integration page states that this base URL is "always" the API base, with the container id as the event id.
- Android packages of white-label apps are named `events.grip.<name><number>`.
- Support addresses are `support@gripcontact.com` or `support@grip.events`.
- Download links are Branch smart links (`<organiser>.app.link/<slug>`, like the `branch_url` on a container record).
- PDFs and footers say "Powered by Grip".
- App-store developer names are usually the organiser's (Hyve Group PLC, Montgomery Group, ASCENTIAL GROUP LIMITED), so the developer field alone does not reveal Grip. The seller shown on Grip's own generic app (App Store id 864239776) is Intros.at ltd.
- Grip's help article "How to add Grip to your developer account on Google Play Console" (fetched 2026-10-07) has organisers invite `mobilebuild+1@intros.at` into their Play Console. Grip builds and ships the app under the organiser's account.
- Privacy policies and ticket small print name the vendor. InspiredMinds' terms for World Summit AI Americas 2027 on tito.io say personal data is shared with "our event networking and community platform provider (such as GRIP)".

### Organiser-level notes

- Grip lists RX Global and Messe Frankfurt among its customer logos. Neither research pass found a 2025 or 2026 RX event with event-level evidence.
- Nothing event-level was found for GL events.
- Comexposium appears only in 2018 to 2020.
- No organiser was found publicly announcing a move away from Grip.
- The Gemini report asserts that Informa "publicly executed a strategic withdrawal" from Grip in early 2026. Its only source is an Event Tech Live article on lead capture. That article says Informa selected Convention Data Services (a registration and lead-retrieval vendor) for North American events, and it does not mention Grip in that context. The live, active Money20/20 USA 2026 and Asia 2026 containers contradict the inference. Treat the claim as unsupported.
